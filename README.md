# Capsule8

Capsule8 was a New York-based cybersecurity company (founded 2016) that built high-performance runtime visibility, detection, and response for Linux production servers and containers across on-premises and cloud workloads. Its open-source sensor exposed a gRPC (v0) telemetry API.

**Acquired by Sophos in July 2021.** The technology was absorbed into Sophos' Adaptive Cybersecurity Ecosystem (Intercept X, XDR, MDR). The capsule8.com domain now redirects to Sophos, the flagship open-source sensor/API repository has been removed, and no independent Capsule8 developer API, portal, or documentation remains live.

- Website (redirects to Sophos): https://capsule8.com/
- GitHub organization (verified, mostly third-party forks): https://github.com/capsule8
